# Trazo

Cuadernos digitales para escribir a mano en Windows: tinta con presión, carpetas y cuadernos ilimitados, stickers, pizarra con diagramas, PDFs y más.

## Descargar

**[⬇ Descargar Trazo para Windows](https://github.com/essanchez-13/trazo-releases/releases/latest/download/Trazo-Setup.exe)**

## Instalar

1. Abre el archivo `Trazo-Setup.exe` que descargaste.
2. Si Windows muestra **"Windows protegió su PC"**, haz clic en **Más información → Ejecutar de todos modos**. Aparece porque la app no tiene firma digital de pago; solo pasa la primera vez.
3. Sigue los pasos del instalador.

Trazo se actualiza solo: cuando hay una versión nueva, la descarga y te avisa para reiniciar.

## Compartir cuadernos

- **PDF**: menú ⋯ del cuaderno → *Exportar PDF*. Se abre en cualquier dispositivo.
- **Archivo Trazo**: menú ⋯ → *Exportar archivo Trazo*. Quien lo reciba lo abre con *Importar* y le queda editable.
